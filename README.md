# MetaLens

MetaLens is a futuristic client-side photo metadata analyzer.

It extracts available:

- EXIF
- GPS
- Camera
- Device
- Lens
- Capture Date
- Digitized Date
- Camera Settings
- Software
- Author
- Copyright
- Color Space
- IPTC
- XMP
- JFIF
- TIFF
- Image information

## Features

- 100% client-side
- No backend required
- No image upload
- GitHub Pages compatible
- Drag & drop
- Mobile responsive
- 3D glassmorphism UI
- Animated metadata core
- GPS map link
- JSON export
- Copy metadata
- Raw metadata viewer

## Deploy to GitHub Pages

1. Create a GitHub repository.

2. Upload:

index.html
style.css
script.js
README.md

3. Open:

Settings → Pages

4. Under:

Build and deployment

select:

Deploy from a branch

5. Select:

main

and:

/ (root)

6. Save.

GitHub will generate your website URL.

## Important

Metadata is only available if the original image still contains it.

Images downloaded from:

- WhatsApp
- Instagram
- Facebook
- Screenshots
- Some editing applications
- Some social media platforms

may have EXIF metadata removed.

MetaLens does not guess missing GPS, device or camera information from the pixels.
